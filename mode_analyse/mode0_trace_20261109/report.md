# mode0 最终 AMVP 特征统计总结（2026-11-09）

**当前候选池存在可利用的固定 MV 码长潜力；但目前所有预设简单选择规则都取得负净收益。历史候选是重要的补充来源，不能据此直接采用“历史优先”或“越新越好”的排序。**

## 数据和统计口径

- 输入：`/ssddata1/V_code/test_results/HHI_500_NNdimd_AMVP_mode_0_trace`，590 份编码日志，38,711,172,068 字节（38.71 GB，十进制），13 个 Class B/C/D 序列。
- RA，QP 22/27/32/37/42；每个序列的 QP×片段矩形完整，片段数为 8 或 10。全部配置为 mode0、AffineAmvpMode0、Scope=final、编码端采样1/1。
- 全部编码有完成标记；对应590份解码日志的 33,525 条POC记录均MD5正确。此帧数包含分段边界重叠。
- 完整扫描所有输入，得到 3,528,046 条最终查询；没有只扫文件前缀，没有原日志变化，没有编码器快照SKIP。
- 另用独立C++扫描器逐条核验全量QUERY/RAW/CAND/END结构、原对/实际预测器码长、15,830,872 条候选的JC/GAIN及池内Oracle：0异常。全量普通记录 2,369,326 条、约束记录 1,158,720 条。此全量检查不重建32维及候选来源，后者通过下述严格抽样验证。
- 离线按完整query做稳定哈希抽样1/20、seed0，保留 176,559 条，压缩为 83,043,425 字节。同一query的全部候选一起保留；离线抽样按参考列表独立进行，双向CU的两条query不保证同时保留。
- 抽样中排除 58,059 条SMVD/强制L1零等约束记录，接受 118,500 条普通FINAL。独立重算全部32维、量化、来源、候选池和收益标签：0拒绝、0审计异常。
- `analysis/report.md`中的分析阶段抽样1/1表示不再二次抽样；真正上游比例是1/20。所有样本数量与收益总量都没有自动乘20。

**查询是一块最终获胜普通平移AMVP的一个活跃参考列表。它不是全部编码CU，也不是ME/RDO试探次数；Merge、IBC、仿射不属于当前特征定义。**

## 扩展候选的潜力

第一候选p0固定，b1为原第二候选。统计池包括b1和新增备选，上限16，另外保留p0作为固定第一槽；它不是旧mode−1/−2的固定八池。

| 项目 | 全量精确结果 | 1/20严格样本对照 |
|---|---:|---:|
| 普通最终查询 | 2,369,326 | 118,500 |
| 原候选对平均估计码长 Jb / bit | 8.279195 | 8.267072 |
| 扩展池最佳第二候选平均估计码长 / bit | 7.640580 | 7.629519 |
| 固定MV Oracle平均潜力 / bit | 0.638615 | 0.637553 |
| 存在严格改善机会 | 20.393% | 20.354% |
| 原0/1已达到池内最小码长（允许并列） | 79.607% | 79.646% |
| 实际最终选择原idx0 / idx1 | 68.066% / 31.934% | 68.060% / 31.940% |
| b1+新增备选平均池大小，不另计p0 | 4.263 | 4.264 |
| 加上p0后的平均不同运动数 | 未在全量重建 | 5.189 |

“原0/1达到Oracle”表示原候选对的最小估计码长与扩展池最佳值相同，不代表最优候选唯一，也不等于实际选择idx0或idx1的比例。

标签固定当前最终MV，计算`Jb=min(EG(v-p0)+idx0, EG(v-b1)+idx1)`，`Jc=min(EG(v-p0)+idx0, EG(v-c)+idx1)`，收益为`Jb-Jc`。**这是EG运动码长代理，含原两个索引的估计代价；不是实际CABAC比特、bins或BD-rate，也不是闭环改变ME之后的上限。**

全量有 483,184 条query可改善，获益query平均可省3.131估计bit。即使总收益占这部分运动EG代理约 7.713%，也绝不能解释为整条码流可省对应百分比。以下特征、历史和规则分析使用1/20严格样本。

## 32维特征目前能说明什么

- F11/F12支持数具有描述性区分：空间支持0、1、2–4的候选正收益比例约5.85%、13.04%、16.60%；历史支持0、1、2–4约5.59%、9.43%、13.30%。但这些组的平均净收益仍为负，不能直接按支持数排序。
- F09/F10覆盖收益不是可靠的单调标签：即使覆盖分数为正，候选替换的平均收益仍可能为负；“更能覆盖邻域”不等于“更能编码当前最终MV”。
- F22历史年龄可作上下文，但年龄最小规则明显退化。原AMVP使用LUT前四槽，满五槽时最新索引4没有进入该范围；“当前可用历史中最新”不等于完整HMVP表最新。
- 历史list类别值得与支持数、覆盖、参考POC距离联合研究；仅另一list候选的潜力较小但非零，不应直接删除。双list共同支持新增候选只有914条query可用，证据稀少。
- F24长期参考在当前候选样本恒0，F30是否B slice恒1；本批无法评价它们的区分能力，不表示其他编码配置下无用。F25–29及F31/32应作为尺寸、精度、参考与缺失状态的上下文。
- F01–08运动差及F15/16离散度适合与上述特征联合评价，当前未训练模型、未做留序列消融，因此没有“32维正式重要性排名”。

候选分箱排除原b1，每条query的其他备选合计权重为1；这些比例不是query级规则命中率，也不能把候选当作相互独立的训练样本。完整数值见[选定特征分箱](tables/selected_feature_bins.csv)。

## 下一步建议

1. 保留原p0和原b1回退，先研究“何时值得替换”，再研究替换成谁。约八成query原对已经达到池内最小估计码长，过度替换很容易抵消少量收益。
2. 标签继续用候选对码长增益，而非候选来源类别或距邻域中值的距离。联合使用候选相对p0/b1、候选与基准的支持差、历史list/年龄、AMVR和参考距离；训练时按query平衡样本，完整序列的全部QP/片段一起留出。
3. 边界覆盖长度可作为新的离线对照，但现有五点采样只能得到观察邻CU的几何代理。不要将其当作论文完整边界扫描结果，仿射/子块邻居尤其需要区分运动覆盖。
4. 只有在留序列固定MV净收益和退化幅度都改善后，再集成新mode并做同一构建、关闭打印的闭环BD-rate。本次不修改编码器、不训练或部署新模型。

## 其他审计与复现

- 原流程实际预测器的ACTUAL_EST与反事实Jb在全量中有 2,465 条不同（0.1040%）；样本对应129条。全量与样本都仅位于整数AMVR的imv1/2；它们的实际预测器和码长本身通过验证。这里只记录原流程与反事实比较口径的差别，不能据此断言编码器错误。
- 调度器的完成打印有100次重复同一解码路径的记录问题；实际590份解码日志均完整且MD5正确。本报告依据实际日志，不依据这100条调度完成打印。
- 文件名可以恢复视频/基础QP/片段，无法仅由日志证明历史二进制或全部源码指纹。没有把本次特征统计解释为新一轮BD-rate实验。
